# List SNPs-to-genes mapping files

List paths to all SNPs-to-genes mapping files generated by
[map_snps_to_genes](https://neurogenomics.github.io/MAGMA_Celltyping/reference/map_snps_to_genes.md).

## Usage

``` r
list_snps_to_genes_files(save_dir, pattern = "*.genes.out$", verbose = TRUE)
```

## Arguments

- save_dir:

  Directory to recursively search for matching files in.

- pattern:

  an optional [regular expression](https://rdrr.io/r/base/regex.html).
  Only file names which match the regular expression will be returned.

- verbose:

  Print messages.

## Value

Named list of paths.
