# Get MAGMA links

Get links to MAGMA executables in the official MAGMA archives.

## Usage

``` r
magma_links(
  latest_only = TRUE,
  os = get_os(),
  version = NULL,
  use_local = TRUE,
  return_table = FALSE,
  verbose = TRUE
)
```

## Arguments

- latest_only:

  Only return the latest version of MAGMA.

- os:

  Operating System.

- version:

  Desired MAGMA version.

- use_local:

  Use a copy of the MAGMA file links, which may be out of date but will
  always be available.

- return_table:

  Return the results in table format.

- verbose:

  Print messages.
