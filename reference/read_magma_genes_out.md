# Read a *.genes.out* file

Read a *.genes.out* file generated by
[map_snps_to_genes](https://neurogenomics.github.io/MAGMA_Celltyping/reference/map_snps_to_genes.md)
as a [data.table](https://rdrr.io/pkg/data.table/man/data.table.html).

## Usage

``` r
read_magma_genes_out(path, verbose = TRUE)
```

## Arguments

- path:

  Path to a MAGMA *.genes.out* file.

- verbose:

  Print messages.

## Value

[data.table](https://rdrr.io/pkg/data.table/man/data.table.html)
