# Find the local executable

Find the local executable for a specific OS.

## Usage

``` r
magma_executable(
  exec_dir = find_install_dir(verbose = FALSE),
  check_exists = FALSE,
  version = NULL,
  return_all = FALSE,
  verbose = FALSE
)
```

## Source

[MAGMA archive](https://ctg.cncr.nl/software/MAGMA/prog/archive/)

## Arguments

- verbose:

  Print messages.

## Value

Path to appropriate executable
