# Find genes.out files

Search for MAGMA output files (genes.out) in a given directory. Support
function for
[get_driver_genes](https://neurogenomics.github.io/MAGMA_Celltyping/reference/get_driver_genes.md).

## Usage

``` r
find_GenesOut_files(GenesOut_dir, verbose = TRUE)
```

## Arguments

- GenesOut_dir:

  Directory to search in.

- verbose:

  Print messages.
