# Select a MAGMA executable

When more than one MAGMA executable is installed, selects one of them to
use.

## Usage

``` r
magma_executable_select(magma_x, return_all = FALSE, verbose = TRUE)
```

## Arguments

- magma_x:

  MAGMA executable.

- return_all:

  Whether to return paths to all MAGMA executables.

- verbose:

  Print messages.
