# Get MAGMA versions

Get the version numbers from each MAGM executable download link.

## Usage

``` r
magma_links_versions(
  links,
  version = NULL,
  return_all = FALSE,
  unique_only = TRUE,
  filter_v = TRUE,
  verbose = TRUE
)
```

## Source

[MAGMA website](https://ctg.cncr.nl/software/magma)

## Value

Character vector of versions.
